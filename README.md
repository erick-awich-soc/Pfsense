## Overview
This repository documents my hands-on learning and practical labs using **pfSense**, an open-source firewall and router platform. The goal is to develop practical skills in network security, firewall administration, and network traffic control.

## Objectives
Understand firewall configuration and management.
  Configure firewall rules and access control.
  Practice Network Address Translation (NAT).
  Learn subnetting, routing, and network segmentation.
  Explore VPN configuration and secure remote access.
  Monitor and troubleshoot network traffic.
  Practice network security using virtual lab environments.
  practice NIDS and NIPS 

## Tools and Technologies
